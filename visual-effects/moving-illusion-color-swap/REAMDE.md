# Visual Effect

Akiyoshi Kitaoka is the author of several optical illusions that trick the brain
into believe motion exists where it doesn't. This page is a presentation of one
such illusion, the moving snakes, but with color selections to allow for easy
exeprimentation with seeing which colors work with the illusion

Examples: https://www.ritsumei.ac.jp/~akitaoka/index-e.html
